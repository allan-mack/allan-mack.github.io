Connect to your real Meraki organization

A Meraki API key carries the full permissions of the admin who created it — there is no "read-only key" by itself. Create a dedicated read-only organization administrator, then generate the key under that account (My profile → API access) so a leak can't be used to change your network. Rotate the key periodically.

Your key is held only in this browser tab for this session — it is never saved to disk. It is sent on every request to the proxy URL you configure below, so only point that field at a relay you operate and trust.

Why a proxy? Web browsers block direct calls to the Meraki API for security (CORS). Run a tiny relay (e.g. a Cloudflare Worker) that forwards requests to api.meraki.com and adds the Access-Control-Allow-Origin header, then paste its URL above. Lock the relay to your own origin and only an api.meraki.com destination. The README has a copy-paste example.
