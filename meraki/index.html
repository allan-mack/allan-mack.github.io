Connect to your real Meraki organization

Create a read-only API key in the Meraki dashboard (My profile → API access). Your key stays in this browser and is never stored or sent anywhere except to Meraki.

Why a proxy? Web browsers block direct calls to the Meraki API for security (CORS). Run a tiny relay (e.g. a Cloudflare Worker) that forwards requests to api.meraki.com and adds the Access-Control-Allow-Origin header, then paste its URL above. The README in this folder has a copy-paste example.
